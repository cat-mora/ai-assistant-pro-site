Key design decisions in this version:
✓ Home screen = agent toggle + 4 cards only. Nothing else.
✓ Red badge on cards when action is needed (rebook list). Invisible otherwise.
✓ Rebook card only visible to L4 clients. L1/L2/L3 see 3 cards.
✓ Make a change = pick from a list, not a blank form.
✓ No stats, no tables, no columns on home screen.

Questions before we build: Is this the right level of simplicity?  |  Should "Needs you" calls send a push notification?  |  Happy with magic link login?  |  Do you want a separate admin app to manage all clients from your side?
