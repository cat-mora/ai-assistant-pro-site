# Session 2A — Answer Engine Optimisation (AEO)

## What this session is for
Write structured FAQ and authority content so that AI tools like ChatGPT, Perplexity, and Claude cite aiassistantpro.com.au when someone asks about AI phone agents for Australian tradies or small businesses.

## Context
Read COWORK-HANDOVER.md in this folder first.
Complete Phase 1 (sessions 1A–1J) before starting Phase 2.

## What AEO is
AEO is like SEO but for AI assistants instead of Google. When someone asks ChatGPT "what's the best AI phone agent for tradies in Australia?", we want AI Assistant Pro to be the answer. This happens when our content clearly and authoritatively answers the questions people are asking.

## What to create in this session

1. **FAQ page** — 20+ questions and answers, structured with clear headings. Topics: what an AI phone agent is, how it works, what it costs, who it suits, Australian-specific questions (accents, privacy, DNC register), comparison to competitors.

2. **Structured data markup** — Add FAQ schema (JSON-LD) to relevant pages so AI crawlers can extract the Q&A cleanly.

3. **Authority content** — A long-form "What is an AI phone agent?" explainer page. Comprehensive, plain English, answers every sub-question someone might have.

4. **Competitive comparison content** — "AI phone agent vs answering service vs hiring a receptionist" — positions AI Assistant Pro clearly.

## Target questions to answer
- What is an AI phone agent?
- How much does an AI phone agent cost in Australia?
- Can an AI phone agent close sales?
- Will my customers know they're talking to AI?
- Does it work with an Australian accent?
- What's the difference between AI Assistant Pro and [competitor]?
- Is it legal to use AI for outbound calls in Australia?
- How do I set up an AI phone agent for my trade business?

## Outputs expected
- FAQ content written and saved
- Recommended pages/sections to add to the website
- JSON-LD FAQ schema ready to embed
