# Session 2B — Programmatic SEO

## What this session is for
Build location + niche landing pages that target Google search traffic from Australian tradies searching for AI phone agents, answering services, or missed call solutions.

## Context
Read COWORK-HANDOVER.md in this folder first.

## Examples of pages to build
- /ai-phone-agent-brisbane-plumbers
- /ai-receptionist-electricians-australia
- /missed-calls-solution-tradies-sydney
- /ai-phone-agent-hvac-melbourne

## Approach
Each page targets a specific niche + location keyword combination. Pages share a template structure but have unique copy for each niche. Claude builds the template and generates the first batch of pages.

## Outputs expected
- Page template built
- First 10 pages generated and deployed
- Sitemap updated
