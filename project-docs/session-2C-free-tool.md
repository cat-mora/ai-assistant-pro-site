# Session 2C — Missed Calls Cost Calculator

## What this session is for
Build a free interactive web tool: "How much are missed calls costing your business?" The tool calculates the annual revenue lost from unanswered calls. It captures email on result and embeds on the website.

## Context
Read COWORK-HANDOVER.md in this folder first.

## Tool inputs
- How many calls do you miss per week? (slider or number input)
- What's your average job value? (dollar input)
- What percentage of callers would have booked? (slider — default 40%)

## Tool output
- Annual missed revenue estimate
- Monthly missed revenue
- Cost of AI Assistant Pro vs cost of missed revenue
- "Your agent pays for itself after [X] extra bookings per month"
- Email capture: "Get your free missed calls audit" → email input → result unlocked or emailed

## Outputs expected
- Complete interactive HTML/JS tool
- Embedded on website (new page or section)
- Email capture connected to Supabase or a simple email list
