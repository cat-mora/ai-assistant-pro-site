# Session 2E — AI Content Repurposing Engine

## What this session is for
Set up a repeatable system: Cathryn records a voice memo or types a rough idea once per week, and Claude automatically turns it into LinkedIn posts, tweets, an email, and a blog post.

## Context
Read COWORK-HANDOVER.md in this folder first.

## The system
1. Cathryn records a voice memo or types a rough idea (2–5 minutes of content)
2. Drops it into a shared folder or pastes it into a Cowork chat
3. Claude produces: 3 LinkedIn posts, 5 tweets, 1 email to the list, 1 blog post draft
4. All content in the AI Assistant Pro brand voice — Australian, plain English, warm
5. Cathryn reviews, edits if needed, schedules/posts

## Outputs expected
- Content templates for each format
- Claude prompt saved for reuse
- First real piece of content produced end to end
