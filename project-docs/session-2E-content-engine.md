# Session 2E — AI Content Repurposing Engine

## What this session is for
Set up a repeatable system where Cathryn shoots 4 short videos per month (one per service level / pain point), ideally in a single batch session, and Claude automatically turns each into content across every channel. Scheduled via Publer. Cathryn shoots — Claude does everything else.

## Context
Read COWORK-HANDOVER.md in this folder first.

## The four monthly videos (one per pain point)

| Video | Pain point | Service level | Angle |
|---|---|---|---|
| Video 1 | Interruption / missed calls | L1 | "What happens when a tradie can't answer the phone" — story/scenario |
| Video 2 | Empty diary / bookings | L2 | "How many bookings are you actually losing" — insight, hooks to calculator |
| Video 3 | Slow lead follow-up | L3 | "Why calling back leads in 60 seconds changes everything" — stat-led |
| Video 4 | Dormant customers | L4 | "The money sitting in your customer list that nobody's calling" — proof-led |

Cathryn records these in one batch session per month (phone camera is fine). Raw video dropped into a shared folder or pasted as a transcript.

## What Claude produces per video

From one video, Claude generates:

| Output | Platform | Notes |
|---|---|---|
| LinkedIn post | LinkedIn | Longer form, professional angle, Cathryn's voice |
| Facebook post | Facebook | Conversational, tradie-aware, hooks to demo or calculator |
| Instagram caption | Instagram | Short, punchy, hooks to link in bio (Linktree) |
| Tweet thread | X | 4–6 tweets, punchy, reachable by non-tradie audience too |
| Email to list | Email | Plain text, one pain point, one CTA |
| Blog post draft | Website | 400–600 words, SEO-aware, links to relevant landing page |
| YouTube description | YouTube | Keyword-rich, includes timestamp markers if applicable |
| Short-form clip caption | Instagram Reels / TikTok | 1–2 lines, hooks to full video |

## Scheduling via Publer

All content scheduled via Publer MCP (already connected).
Workflow:
1. Claude generates all content formats
2. Cathryn reviews and approves (or edits)
3. Claude schedules via Publer across all platforms
4. Cathryn does nothing else

Publer MCP tools available: `list_accounts`, `schedule_post`, `create_draft`, `delete_post`

## Brand voice rules for all content

- Australian English always
- Plain English — no corporate jargon, no AI buzzwords
- Practical and specific — real scenarios, real numbers where possible
- Cathryn's voice — direct, knowledgeable, not salesy
- Never use: "warm", "exciting", "leverage", "seamlessly", "innovative"
- Always link to: relevant landing page, demo, or calculator — not just the homepage

## Outputs expected
- Content templates for each format (saved and reusable)
- Claude prompt saved for reuse each month
- Publer scheduling workflow confirmed working
- First full month of content produced end to end (4 videos → all formats → scheduled)
- Content calendar structure agreed (which day/time each platform posts)
