Write two versions of Facebook/Instagram ad copy, set up Meta Business Manager, and launch the first campaign targeting Australian tradies.

## Context
Read COWORK-HANDOVER.md in this folder first.
Complete Phase 1 and Phase 2 before running paid ads.

### Version B — Demo-focused

## Campaign setup

- Objective: Lead generation / Traffic to /tradies

- Budget: $20–30/day to start
- Destination: www.aiassistantpro.com.au/tradies

## Outputs expected
